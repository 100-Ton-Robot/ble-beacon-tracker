# Antennas

Antenna designs either build of the mast can use, beside the stock HiRO H50327 ducks. Antenna choice and the RF
comparison for the ducks are in [`docs/ANTENNA_SELECTION.md`](../docs/ANTENNA_SELECTION.md); the sector model is in
[`rf_model/`](../rf_model/README.md).

| Folder | Antenna | Status |
| --- | --- | --- |
| [`printed_fin/`](printed_fin/README.md) | Printed half-wave dipole on a small double-sided FR-4 fin, standing out from each face over the centre hole; hand-made (score and peel) from a 1:1 template | **shelved, not tested**: simulation only, never built or measured |

Nothing in this folder is thrown away when it is shelved: the code, every simulation run and the templates stay, with
the reason it was shelved and what would have to change to pick it up again.
