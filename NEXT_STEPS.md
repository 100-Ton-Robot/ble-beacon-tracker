# Next steps

Open work is tracked in **GitHub issues**: https://github.com/100-Ton-Robot/ble-beacon-tracker/issues
(moved from this file 2026-11-20, issues #1-#12).

How issues are written, by people and Claude sessions alike:

- One item per issue: a short summary, a checklist when there are steps, and a last line
  `Doc: <path>` pointing at the detailed doc in this repo (pushed, so every session can read it).
- Labels: area (`gateway`, `scanner_fw`, `shield_deck`, `repo`), owner (`owner:aaron`,
  `owner:gateway-session`, `owner:scanner-session`; none = anyone), `decision` (Aaron decides),
  `blocked` (waiting on the issue named in the body; remove the label when that one closes).
- Close an issue with the commit or result that finishes it; the change itself still gets its
  `CHANGELOG.md` entry.
